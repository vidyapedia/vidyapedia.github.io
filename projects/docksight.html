01 / Problem

Docking fails when the target leaves the camera.

A controller can reduce position error and still make the perception problem impossible. During a close-range approach, aggressive rotation or lateral misalignment can push the AprilTag out of frame, removing the measurement needed to finish the maneuver.

Design questionHow can a mobile robot reach a docking pose while keeping the visual target measurable throughout the approach?

02 / System

A small stack with explicit signals.

The prototype uses a Raspberry Pi 4 and Pi Camera v2 to detect AprilTag ID 0. Calibrated image geometry turns the tag observation into the control signals that matter: center error, bearing, range, and field-of-view margin.

03 / Control logic

Reactive baseline first, constrained optimization next.

The baseline controller is organized as a legible finite-state machine: searching for the tag, aligning bearing, approaching, recentering when visibility degrades, declaring docked, and safely stopping after persistent tag loss.

Searching

Rotate until the target is detected with a stable observation.

Aligning

Reduce horizontal image error before committing to forward motion.

Approaching

Advance while monitoring bearing, range, and visibility margin.

Recentering

Interrupt the approach when the target nears the image boundary.

Docked / Lost

Stop at the terminal range or fail safely when measurement is persistently unavailable.

The research formulation compares that baseline with standard nonlinear model predictive control and an NMPC controller whose constraints explicitly preserve target visibility.

04 / Validation

Log what the robot sees and what it decides.

The evaluation records bearing, range, field-of-view margin, controller state, motor commands, detection status, and docking outcome. This makes failure modes inspectable instead of reducing the experiment to a final success / failure label.

05 / Iteration

Build the evidence in layers.

The project began with reliable tag detection and measurement, then moved through motor calibration and closed-loop rotation. Approach, stop, visibility-margin enforcement, and comparative controller trials extend the same logging-first workflow.

Engineering principleA sophisticated controller is only useful when sensing, actuation, timing, and failure behavior are all measurable and reproducible.
